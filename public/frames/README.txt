  frame-03.webp   network topology hologram      -> Spotify Engineering Pipeline card
  frame-04.webp   backlit keyboard               -> hero background texture

  frame-06.webp   n8n workflow diagram           -> Decodelabs experience entry

Originals are archived in frames-source/ at the repository root.
To replace a visual, drop a new image (jpg/png/webp) here as frame-0X.<ext>
and run:  python scripts/process_frames.py
